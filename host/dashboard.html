GPUs shown on display

Choose which GPUs appear in the detail pages. Your choices are saved on the device for this computer. The activity bar averages enabled GPUs that report load.

Unavailable sensors display “--”. NVIDIA telemetry uses your existing driver. GPU activity is the average of enabled GPUs reporting utilization; disabled GPUs and missing readings are excluded. Each visible GPU summary shows its own temperature, load, memory and power. CPU temperature availability depends on the operating system and hardware. On Windows, an existing LibreHardwareMonitor WMI source or the optional sensor helper can supply readings. Local AI detection supports Maestro, llama.cpp, Ollama, LM Studio, KoboldCPP, vLLM, SGLang, TGI and MLX LM. Active means a local job or inference request was reported. Loaded means a resident model with unavailable activity data. Engine running means a recognized worker with unavailable API telemetry. No source means detection could not establish a local AI source. CPU and RAM refer to the selected worker; token rates and KV cache require engine telemetry. Monitor installs no drivers. Standard-user sensors are read automatically. Generic thermal zones are labelled separately from CPU die temperatures. On Windows, the optional CPU sensor helper asks for approval once and remembers access on this PC. Later launches read silently; turning the option off stops the reader. A compatible existing sensor driver is required.
