# Security and privacy

The dashboard binds only to loopback and requires a random per-run token for its APIs. Keep that session URL private. No cloud account is required for ordinary monitoring. Local AI detection may query recognized local engine endpoints; release/build downloads and opening documentation/donation links are explicit network actions.

The host can inspect local process and hardware information. Review the source and your organization's policy before use. Native sensor access depends on OS permissions. The optional Windows CPU reader is an explicitly approved, restricted read-only helper; the main host is not automatically elevated.

Never add antivirus exclusions or bypass device, driver, signing or enterprise policy merely to run this project.

Do not post secrets or exploit details publicly. Report a security concern to the maintainer through GitHub's private reporting option if available; otherwise open a minimal issue requesting a private contact route without including sensitive details.
